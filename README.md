# BIC21203 Web Development – Lab 4(B)

## Client-Side Scripting (JSON and jQuery)

**Course:** BIC21203 Web Development  
**Lab:** Lab 4(B)  
**Academic Session:** 2026/2027

## 1. Introduction

This laboratory focuses on JSON data handling, retrieving and displaying JSON data using JavaScript fetch(), and performing DOM manipulation using jQuery.

## 2. Files Included

- `books.json` – Contains information about two books.
- `books.html` – Retrieves and displays JSON data using the fetch() API.
- `jquery-dom.html` – Demonstrates DOM manipulation and event handling using jQuery.

## 3. Setup Instructions

1. Download or clone this repository.
2. Open the project folder using Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click `books.html` and select **Open with Live Server**.
5. The browser will display the book information retrieved from `books.json`.
6. To test jQuery, open `jquery-dom.html` using your browser.

**Note:** An internet connection is required to load the jQuery CDN.
